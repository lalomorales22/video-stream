Setup

Get your studio ready

Three steps, top to bottom. Your cameras and their OBS links already work without any of this — these steps add the automatic parts.

  1. 1

    Connect to OBS

    not checked

    Lets this app switch scenes, save replays and build scenes for you.

    In OBS, open Tools → WebSocket Server Settings, tick Enable WebSocket server, then click Show Connect Info and paste the password here.
  2. 2

    Give each camera a scene

    The auto-director switches between scenes, so each camera needs one. Let the app make them, or point it at scenes you already built.

  3. 3

    Check everything

    Run this before you go live. Anything that fails gets a button that fixes it.
